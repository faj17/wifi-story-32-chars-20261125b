One original funny Wi-Fi network name (29 characters):

> Ex moved out, kept the router

The setup is a breakup move-out — the ex has gone. The twist lands in the last three words: the ex kept the router, so the network name you are reading in your phone's list is a passive-aggressive monument to the very box that was taken. Situation, character and event are all in there: a split, an ex, a stolen router. Nothing in it explains its own joke, and every character earns its place.

## Run it

```sh
python3 main.py
```

Writes the name to `/output/entry.txt`.
